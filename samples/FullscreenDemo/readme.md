# FullscreenDemo

The FullscreenDemo is a single-screen “dashboard” style demo designed to exercise layout, focus navigation, and overall styling.

![FullscreenDemo screenshot](https://raw.githubusercontent.com/XenoAtom/XenoAtom.Terminal.UI/main/site/img/fullscreen.png)

## Run from source

```shell
dotnet run -c Release --project samples/FullscreenDemo
```

While the demo is running, press `Ctrl+F12` to copy the current app frame as a PNG screenshot to the clipboard. The command is also surfaced in the command bar by default.

## Install as a .NET tool (planned)

```shell
dotnet tool install -g XenoAtom.Terminal.UI.FullscreenDemo
xenoatom-fullscreen-demo
```
